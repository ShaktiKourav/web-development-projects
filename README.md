### 2. Interactive To-Do List

A dynamic task management application that allows users to add, complete, undo, and delete tasks.

**Key Features:**

* Add tasks
* Complete and undo tasks
* Delete individual tasks
* Clear all tasks
* Enter key support
* Task counter
* LocalStorage persistence
* Responsive design

**Technologies:** HTML5, CSS3, JavaScript, DOM Manipulation, LocalStorage

[View Project](./todo-list/)

### 3. Responsive Product Pricing Cards

A modern SaaS-style pricing component with interactive monthly and yearly billing options.

**Key Features:**

* Monthly/Yearly billing toggle
* Dynamic price updates
* Popular plan badge
* Best Value badge
* CSS hover animations
* CSS transitions
* Responsive pricing layout

**Technologies:** HTML5, CSS3, JavaScript, CSS Grid, CSS Transitions

[View Project](./pricing-cards/)

---

### 4. Live Weather Dashboard

A responsive weather application that fetches real-time weather information using the Fetch API.

**Key Features:**

* Search weather by city
* Current temperature
* Weather condition and icon
* Humidity
* Wind speed
* Feels-like temperature
* 5-day forecast
* Input validation
* Error handling
* Enter key support
* Dynamic DOM rendering

**Technologies:** HTML5, CSS3, JavaScript, Fetch API, Async/Await, Open-Meteo API

[View Project](./weather-dashboard/)

---

### 5. Interactive Mini E-Commerce App

A beginner-friendly e-commerce application with dynamic products, shopping cart functionality, and checkout preview.

**Key Features:**

* Dynamic product rendering
* Product cards
* Add to cart
* Increase/decrease quantity
* Remove items
* Cart item count
* Automatic total price calculation
* Shopping cart modal
* Checkout preview modal
* Order confirmation
* Responsive design

**Technologies:** HTML5, CSS3, JavaScript, DOM Manipulation, JavaScript Objects, Array Methods, CSS Grid

[View Project](./mini-ecommerce/)

# Interactive Mini E-Commerce App

A responsive and interactive mini e-commerce web application built using HTML, CSS, and JavaScript.

## Features

* Dynamic product rendering from JavaScript objects
* Product cards with name, description, price, and icon
* Add products to shopping cart
* Increase and decrease product quantity
* Remove products from cart
* Dynamic cart item count
* Automatic total price calculation
* Shopping cart modal
* Checkout preview modal
* Order confirmation
* Empty cart validation
* Responsive design for desktop, tablet, and mobile
* Hover effects and smooth UI interactions

## How It Works

1. Product information is stored inside a JavaScript array of objects.
2. JavaScript dynamically creates product cards on the webpage.
3. When the user clicks "Add to Cart", the selected product is added to the cart.
4. If the product already exists in the cart, its quantity is increased.
5. The cart count and total price are updated automatically.
6. Users can increase, decrease, or remove products.
7. The checkout button opens an order preview modal.
8. The user can confirm the order from the checkout preview.
9. After confirmation, the cart is cleared.

# Responsive Product Pricing Cards

A modern and responsive SaaS pricing card component built using HTML, CSS, and JavaScript.

## Features

- Monthly and Yearly billing toggle
- Dynamic price updates using JavaScript
- Popular plan badge
- Best Value plan badge
- Responsive pricing card layout
- CSS hover animations
- CSS transitions and transform effects
- Responsive design for mobile, tablet, and desktop
- Clean and modern SaaS-style interface

## Pricing Plans

### Basic
- Monthly: $9/month
- Yearly: $7/month

### Pro
- Monthly: $19/month
- Yearly: $15/month
- Popular Plan

### Business
- Monthly: $39/month
- Yearly: $31/month
- Best Value Plan

# Interactive To-Do List with LocalStorage

A responsive and interactive To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete individual tasks
- Clear all tasks
- Add tasks using the Enter key
- Task count display
- LocalStorage data persistence
- Tasks remain available after page reload
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- LocalStorage

## Key JavaScript Concepts

This project demonstrates:

- DOM element selection
- Creating and modifying HTML elements
- Click event handling
- Keyboard event handling
- JavaScript arrays and objects
- Array methods such as `push()`, `map()`, and `filter()`
- LocalStorage
- JSON `stringify()` and `parse()`
- Dynamic UI rendering

# Live Weather Dashboard with Fetch API

A responsive weather dashboard that fetches real-time weather information and displays a 5-day forecast for any searched city.

## Features

- Search weather by city name
- Real-time temperature
- Weather condition and weather icon
- Humidity information
- Wind speed
- Feels-like temperature
- 5-day weather forecast
- Search validation
- Error handling for invalid cities
- Enter key support
- Responsive design
- Dynamic DOM rendering
- Asynchronous JavaScript using fetch and async/await
- No API key required

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- DOM Manipulation
- CSS Grid
- Responsive Media Queries
- Open-Meteo Weather API

## Key JavaScript Concepts

This project demonstrates:

- API requests using `fetch()`
- Asynchronous programming
- `async` and `await`
- JSON response handling
- Dynamic DOM element creation
- Event listeners
- Input validation
- Error handling using `try...catch`
- JavaScript template literals

## API

This project uses the Open-Meteo API for weather and geocoding data.

No API key is required.
